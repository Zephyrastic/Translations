# Skinhub Translations

Community-maintained translations for **Skinhub**.

This repository contains the language files used by Skinhub and is open to anyone who wants to help improve existing translations or add support for new languages.

## Contributing

Contributions are welcome!

You can contribute by:

* Fixing incorrect translations
* Improving awkward or unnatural wording
* Correcting spelling or grammar
* Adding missing translations
* Adding support for a new language
